# Конвенція повідомлень комітів

- **spec:** зміни у специфікаціях та вимогах (файли у /spec)
- **test:** створення або зміна тестів (/src/test)
- **feat:** розробка нового функціоналу та написання коду (/src/main)
- **docs:** супровідна документація та звіти (/docs)
- **gate:** фіксація контрольних точок GIT-GATE
- **chore:** рутинні налаштування або структура
