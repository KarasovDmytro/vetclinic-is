## Примітки

- **Покриття.** Усі REQ-F-001…048 та REQ-NF-001…005 розподілені між модулями. Кожен Feature має парний Test (003→004, 005→006, 007→008, 009→010, 011→012, 013→014).
- **Тестовий бар'єр.** TSK-015 залежить від усіх шести Test і блокує всі шість Feature. Тести пишуться паралельно двома групами: TSK-005, 007, 011 стартують одразу після PLAN-GATE, а TSK-003, 009, 013 чекають на Addendum TSK-002. Жоден Feature не стартує до завершення рев'ю.
- **Порядок для діаграми Ганта.**
  1. Gate і Addendum (001–002).
  2. Тести всіх модулів (003, 005, 007, 009, 011, 013) у двох групах паралельно.
  3. Рев'ю тестів (015).
  4. Feature у порядку 004, потім 006 і 008, потім 010, 012, 014.
  5. Code review, документація та валідація (016–018).
  6. Release Gate (019).
- **Залежності Feature.** TSK-004 блокує всі наступні Feature (рольовий доступ). Залежність кожного Feature від TSK-015 вказана явно.
- **Addendum.** Чотири логічні діри SRS об'єднано в один тікет TSK-002. Якщо після PLAN-GATE їх визнають неістотними, тікет можна прибрати, і залишиться 18 тікетів.
